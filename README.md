# 小三的逆向笔记

记录 Android native so 脱壳、反混淆与 Frida / IDA 逆向实战。

在线地址：<https://xiaosan-re.github.io>

## 本地预览

```bash
bundle install
bundle exec jekyll serve
```

然后浏览器打开 <http://127.0.0.1:4000>。

## 目录说明

- `_posts/` 博客文章
- `_config.yml` 站点配置
- `_data/` 技能、社交、友链等数据
- `pages/` 关于、404 等独立页面
- `assets/` `images/` 静态资源
